**Global Solar Scheduler** is a Python-based GUI application designed to simplify international meeting coordination. Built with `customtkinter`, it features a real-time world clock dashboard that tracks 20+ global cities, providing not just local times but also astronomical data (sunrise/sunset) and Daylight Saving Time (DST) status.

Key capabilities include:

* **Smart Scheduling Logic:** Automatically converts meeting times between time zones and assesses suitability (e.g., flagging times that fall during a client's sleeping hours).
* **Holiday Integration:** Checks against a global holiday database to prevent scheduling conflicts with international clients.
* **Persistent Database:** Saves all scheduled meetings to a local JSON database, ensuring data retention across sessions.
* **Audio Alarm System:** Features a multi-threaded alarm system using `pygame` that plays custom MP3 alerts for upcoming meetings, with instant stop functionality upon acknowledgment.

This tool solves the common friction points of working in global engineering teams by centralizing time, solar, and calendar data into a single intuitive interface.# Jackfruit_project
